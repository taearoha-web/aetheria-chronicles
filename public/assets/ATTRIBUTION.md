# Character asset provenance

The game uses real textured, skeletal 3D character models. These files are not covered by the source-code license as a blanket collection.

## User project models

The knight, healer and mage models were reused from the user's existing **Seven Elements** game project. These are existing original Tripo-derived models with subsequent Blender optimization, skinning and authored combat clips. No new paid generation was performed for this game. The original provider license and the user's rights continue to apply; these files are not represented as CC0.

| Delivered file | Original project file | Visual identity |
| --- | --- | --- |
| `knight.glb` | `assets/paladins_v1_r6/water_paladin.glb` | Silver-armored male sword-and-shield knight |
| `healer.glb` | `assets/scroll_monsters_v3/light_mermaid.glb` | Golden female light spirit with a mermaid silhouette |
| `mage.glb` | `assets/scroll_monsters_v3/fire_mermaid.glb` | Red-haired female flame spirit with a mermaid silhouette |

The three PNG portraits are existing renders from the same project. All three models contain ten named skeletal animation clips, including idle, attack, movement, damage, death and skill actions.

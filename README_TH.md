## เมืองและNPC

นครแสงอรุณเป็นแมพเฉพาะ ไม่มีมอนสเตอร์ บอส หรือศิลาต่อสู้ ล้อมด้วยรั้วไม้ที่กันการเดินและหลบทะลุได้ มีประตูเหนือเปิดเมื่อเข้าใกล้ เดินผ่านประตูเพื่อเข้าสู่ด่าน1 “ทุ่งศิลาอรุณ” ใช้ประตูกลับเมืองของด่านหรือเมนูกลับเมืองเพื่อกลับมาพัก

NPCใหม่ทั้ง6คนใช้แอตลาสเฉพาะ แยกจากภาพนักดาบ/ธนู/เวท มี6เฟรมต่อคนและขนาดสัดส่วนต่างกัน:

| NPC | งานและแอนิเมชัน | บริการ |
|---|---|---|
| ลูนา | หญิงสูงวัยแว่นกลม อ่านแผนที่ ชี้และทักทาย | ภารกิจ/รางวัล |
| โบ | พ่อค้าร่างท้วม ตรวจและยกขวดยา | ซื้อยาHP/MP |
| อัคร | ช่างแคระเคราเทา ยกค้อนตีทั่งและประกายไฟ | ตีบวกถึง+5 |
| เอเรน | ผู้รักษาชุดขาวฟ้า ถักเปีย ร่ายแสงด้วยฝ่ามือ | รักษาHP/MP |
| เซริน | เจ้าหน้าที่จิ้งจอกใส่แว่น เขียนบัญชีและเปิดสมุด | คลังอุปกรณ์ |
| โอริน | ยามสูงวัยหมวกทอง ยกโคม พยักหน้าและชูกุญแจ | แผนที่เดินทาง |

กดM/ปุ่มแผนที่ → ผังเมือง/หาNPC → เดินไปจุดนี้ ตัวละครเดินอ้อมสิ่งกีดขวางไปถึงสถานี แล้วกดEเพื่อคุย NPCทำงานประจำที่ด้วยสไปรต์หลายเฟรม ไม่ได้ใช้ท่าเดินแปดมุม โหมดเมนูพักการจำลองเกม

## ต่อสู้และของดรอป

ด่านทั้ง10แยกจากเมือง: ทุ่งศิลาอรุณ พงไพรกระซิบ ชายฝั่งมุกคราม สุสานจันทรา นครทรายลืมเลือน หุบเขาเหมันต์ บึงหิ่งห้อย ภูผาเพลิง วิหารเหนือเมฆ และปราสาทอุปราคา ทุกด่านมีมอนสเตอร์ ศิลา3จุด หีบ และบอส ปลุกศิลาเพื่อเปิดบอส ผ่านบอสก่อนหน้าเพื่อปลดด่านถัดไป กลับลูนารับรางวัลได้ครั้งเดียวต่อด่าน

WASD/ลูกศร/จอยซ้ายเดิน · แตะพื้นหาเส้นทาง · แตะมอนสเตอร์เข้าระยะโจมตี · J/ปุ่มใหญ่โจมตีค้างได้ · 1–3ใช้สกิล · Spaceหลบ · Q/Rยา · Eสำรวจ · Iกระเป๋า · Mแผนที่ · Escapeพักเกม

เลเวลตัน30 ได้แต้ม3แต้มต่อเลเวล สกิลปลดLv1/4/8: นักดาบฟันกวาด/พายุดาบ/โล่, นักธนูศรสามดอก/ทะลวง/เถาวัลย์, นักเวทไฟ/น้ำแข็ง/สายฟ้า โจมตีปกติไม่ใช้มานา สกิลมีMP/คูลดาวน์/จังหวะง้างและเกิดผลจริง

ทอง วัสดุ ยา และอุปกรณ์มีชื่อ/สีบนพื้นก่อนเก็บ เดินใกล้เพื่อรับ เปิดกระเป๋าสวมอาวุธ/เกราะ/แหวน เทียบค่า ล็อก ย่อย เก็บคลัง และตีบวกสูงสุด+5 อุปกรณ์เปลี่ยนค่าสถานะ/แสง ยังไม่มีชุดสไปรต์แยกลุคครบทุกไอเทม

## เซฟและรุ่นเดิม

ยังใช้key emberfall-adventure-v2/schema2 จัดวางโลกเป็นtownLayout4 เซฟเมืองเก่าที่ใช้id dawnจะย้ายตัวละครเข้าจุดพักของtownครั้งเดียว เลเวล/อาชีพ/ทอง/อุปกรณ์/แต้ม/ผลเควสต์ยังอยู่ ของค้างบนพื้นเมืองเก่าย้ายเข้าจุดพักโดยเก็บID/แรร์เดิม ผลบอสdawnเดิมนับเป็นความคืบหน้าด่าน1 เซฟที่อยู่ด่านอื่นเก็บตำแหน่งเดิม และไฟล์นำเข้าเสียไม่ทับเซฟก่อนหน้า

ยังรองรับย้ายเลเวล/ทอง/ยาจากตัวอย่างv1แบบเลือกเอง ไม่ลบkeyเดิม Export/ImportJSONอยู่ในเมนู iOSอาจล้างข้อมูลเว็บไซต์ ควรสำรองเซฟเป็นระยะ
